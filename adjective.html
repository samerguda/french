1. Les adjectifs de base et leurs contraires (1–25) — الصفات الأساسية وعكسها

  1. Cette maison est grande.هذا المنزل كبير.
  2. Cette maison est petite.هذا المنزل صغير.
  3. Mon frère est grand.أخي طويل القامة.
  4. Mon frère est petit.أخي قصير القامة.
  5. Le sac est lourd.الحقيبة ثقيلة.
  6. Le sac est léger.الحقيبة خفيفة.
  7. Cette rue est longue.هذا الشارع طويل.
  8. Cette rue est courte.هذا الشارع قصير.
  9. Le mur est haut.الحائط مرتفع.
  10. Le mur est bas.الحائط منخفض.
  11. Cette table est large.هذه الطاولة عريضة.
  12. Cette table est étroite.هذه الطاولة ضيقة.
  13. Le bâtiment est vieux.المبنى قديم.
  14. Le bâtiment est neuf.المبنى جديد تمامًا.
  15. Cette voiture est rapide.هذه السيارة سريعة.
  16. Cette voiture est lente.هذه السيارة بطيئة.
  17. Le café est chaud.القهوة ساخنة.
  18. Le café est froid.القهوة باردة.
  19. L’eau est propre.الماء نظيف.
  20. L’eau est sale.الماء متسخ.
  21. La boîte est pleine.العلبة ممتلئة.
  22. La boîte est vide.العلبة فارغة.
  23. Cette porte est ouverte.هذا الباب مفتوح.
  24. Cette porte est fermée.هذا الباب مغلق.
  25. Le magasin est proche.المتجر قريب.
